Esta automatización que ves aquí funciona y la creen menos de un minuto. De hecho, yo no toque ni un solo nodo, sino que Cloud lo hizo todo por mí. Literalmente solo escribió lo que quede a crear y al rato me devolvíon enlace que llevaba directamente a mi flujo dentro de Ne8n. Y ahora seguramente te estés preguntando cómo se hace. Vamos paso a paso. Primero, entra la web de Cloud, descarga la aplicación de escritorio e inicia sesión de forma normal. Después, instala no. Ya que es lo que permite que Cloud pueda comunicarse con el servidor mcp y ejecutar tus automatizaciones. Luego, abre el repositorio de Ne8n para mcp en github, copia el primer comando que aparece y piegaló en tu terminal. Con eso, el servidor ya queda corriendo y listo para usarse. Ahora, abre Cloud Desktop, vea la partada de configuraciones, entra la sección para desarrolladores y da la botón que dice editar configuración. Ahí dentro, pega el bloque de código del repositorio, que aparece justo debajo del comando que acabas de ejecutar. Simplemente, hacen falta completar tus campos, la URL de tu instancia de Ne8n y tu clave API. La URL la puedes copiar desde la barra de navegación de Ne8n cogiendo únicamente el dominio. Y la clave API puedes generarla directamente desde la partada de configuraciones en la sección de apikis. Una vez pegado a los datos, guarda, cerra Cloud y vuelvo a abrirlo. Ahora, ya verás el conector en Ne8n mcp con todas las herramientas disponibles en el panel. Desde aquí ya puedes pedir la cloud que construye automatizaciones enteras a partir de una simbliestrucción el lenguaje natural. Pero ahora viene la mala noticia, y es que, para que todo esto funcione, lo más importante es el prompt. En el modelo no sabrá cómo crear los flujos correctamente y no servirá de nada. Si quieres que te envía la guía completa con el paso a paso para configurar todo esto dentro de Ne8n, comenta la palabra y te la mando totalmente gratis.
