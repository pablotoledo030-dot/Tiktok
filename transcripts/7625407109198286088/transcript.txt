La mayoría de la gente no sabe que existe un programa que se integra a la protección con Cloud Code para ofrecerte en mejor segundo cerebro basado en trigencer. Se llama Obsidian y la razón por la que funcionamos también es que está totalmente basado en activos Macdown, algo en lo que Cloud Code destaca. A continuación te explico cómo puedes configurarlo y cómo lo utilizo yo para mi cerebro de día. En primer lugar debes descargar Obsidian y crear tu primer port. Después debes indicar la Cloud Code que crea una carpeta del proyecto en la que vas a colocar ese bot. Y por último, bajar a instrucciones al archivo Cloud.md de esa carpeta del proyecto sobre cómo recopilar y almacenar información de esto de tu Obsidian. Como consejo rápido puedes crear un sistema utilizando la herramienta web page Cloud Code para decir de que obligar información de casi cualquier página web y almacenarla mediante un sistema de conocimiento como el sistema Set of Custom. Y ahora en lugar del limbo de la carpeta de guardados ahora tienes un sistema de conocimiento que tiene este aspecto y que Cloud Code pueden navegar y utilizar para para quitar el proyecto.
